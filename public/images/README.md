# Attraction Images

Place only approved, licensed attraction images in this directory.

When a record in `src/data/attractions.json` has an image, set `image.src` to
`/images/<filename>` and provide localized `image.alt.en` and `image.alt.ar`
text. Omit the `image` field entirely when no approved media is available.

Do not place base64 payloads in the JSON catalog.
